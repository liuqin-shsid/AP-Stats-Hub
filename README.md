# AP Stats 小站

这是可直接发布的静态网站。请保持以下文件位于同一文件夹：

- `index.html`
- `style.css`
- `app.js`
- `scatterplot.js`
- `outliers.js`
- `linear-function.js`
- `linear-regression-data.xlsx`
- `burger-king-menu-items.xls`

左侧“线性回归教学”包含四个工具：

- **相关关系探究 / Correlation Explorer**：保留原来的页面布局、拖动数据点、删除模式、拟合直线和统计指标。
- **散点图 / Scatterplot**：左图展示 Excel 原始数据，右图展示缩放和平移后的数据。两个工具分别保留自己的案例、变量和调整状态，切换工具不会互相覆盖。
- **异常值点 / Outliers**：从空白坐标图开始，自行添加、删除、拖动点，实时显示 X/Y 均值、样本标准差、相关系数 r 和 R²。该工具不依赖 Excel 数据。
- **线性函数 / Linear Function**：使用汉堡王餐品的脂肪与蛋白质数据，通过自由拖线、双均值点吸附、旋转和标准化图探索竖直残差及平均残差平方。

散点图操作：

1. 选择案例以及 X、Y 变量，两图使用同一份 Excel 数据。
2. “数据缩放与平移”拉杆只控制右图，先平移、再缩放：`X′ = a × (X + b)`、`Y′ = c × (Y + d)`。左图的数据和坐标范围固定；右图坐标轴随结果自动适配。负倍数会翻转，零倍数会使变量成为常数，此时相关系数未定义。
3. 两图显示 X/Y 均值和样本标准差（分母为 `n − 1`），统计量基于图中的有效数值配对。滑块旁标注原始均值及标准差倒数，并提供“减去 x̄ / ȳ”和“乘以 1/sₓ / 1/sᵧ”快捷按钮。分别点击平移与缩放按钮即可得到 `(X − x̄)/sₓ`、`(Y − ȳ)/sᵧ`，变换后均值为 0、样本标准差为 1。标准差为 0 或点数不足时，缩放快捷按钮不可用。
4. 快捷按钮设置对应参数，重复点击不会累加；内部使用精确计算值，面板数值仅作显示取舍。拉杆范围自动涵盖标准化目标。“重置调整”恢复原始变换。切换案例或变量也会重置调整。
5. 右上角切换中文、英文。
6. 右图的 X、Y 都完成标准化后，显示 X = 0 和 Y = 0 两条轴。第一、三象限的点为橘色，第二、四象限为绿色，任一轴上的点（含原点）为蓝色，不显示颜色图例。仅一个变量标准化或重置后，恢复原来的单色显示。零附近 1e−12 内的浮点误差按轴上点处理。

“5.身高-体重”的 Excel 第 2、3 行已作为教学示例调整：第一点的身高等于整组身高均值，第二点的体重等于整组体重均值，其余两个坐标配平以保持两列均值不变。X/Y 都标准化后，分别出现一个位于 X = 0、一个位于 Y = 0 的蓝色点。Excel 内保留完整数值精度，其他数据点不变。

异常值点操作：

1. 点击坐标区域空白处添加点；点击已有点删除。按住点移动超过 5 像素视为拖动，拖动结束不会删除点。支持鼠标和触摸；坐标记录到小数点后两位。
2. X/Y 坐标轴固定为 0 至 20，方便对照每次添加和移动的影响。图上点可用方向键每次移动 0.1，Delete / Enter 可删除聚焦的点。
3. 统计量随拖动实时更新；样本标准差为 √[Σ(值 − 均值)² / (n − 1)]，R² = r²。没有点时不显示均值；不足两个点时不显示样本标准差、r 和 R²；X 或 Y 为常数时 r 和 R² 未定义。
4. “撤销上一步”可恢复最近 50 次添加、删除、拖动或清空操作。四个工具的状态相互独立，在工具间切换会保留；刷新网页会重置。

线性函数操作：

1. 图中使用 `burger-king-menu-items.xls` 的“第二节数据”工作表，共 32 项餐品；X 是脂肪含量，Y 是蛋白质含量。双均值点 `(x̄, ȳ)` 起初隐藏。
2. 在图内任意位置按住鼠标或触控笔并拖出一小段，松开后网页会把线段延长成完整直线。红色竖直短线表示每个餐品的残差 `d = y − ŷ`。线段太接近竖直时会提示横向多拖一些。
3. 当直线进入双均值点附近时，网页会自动把直线吸附到双均值点，并显示紫色双均值点及其数值。吸附范围为当前 Y 显示跨度的 3%，图中不显示范围边界。
4. 吸附后会显示残差正方形，每个正方形的边长为 `|d|`，并显示 `MSR = Σ(y − ŷ)²/(n − 1)`。标准化图使用 `MSR = Σ(zᵧ − ẑᵧ)²/(n − 1)`。拖动线上的紫色圆环可围绕双均值点旋转，MSR 随之实时变化。
5. 开启“标准化模式”后，右侧出现标准化图。双均值点变为原点 `(0, 0)`，直线、残差、残差正方形和 MSR 与左图同步变化。第一、三象限为橘色，第二、四象限为绿色，坐标轴上的点为蓝色；也可拖动右图的紫色圆环旋转。
6. 点击“重新选线”会清除当前直线和选点，保留标准化模式的开关状态。

发布步骤：

1. 登录 GitHub，点击右上角的 **+ → New repository**，仓库名可填写 `ap-stats-site`，选择 **Public**，然后点击 **Create repository**。
2. 在新仓库点击 **Add file → Upload files**，把上面列出的八个文件全部拖进去，点击 **Commit changes**。
3. 点击仓库上方的 **Settings → Pages**；在 **Build and deployment** 中将 Source 设为 **Deploy from a branch**，Branch 选择 **main** 和 **/(root)**，点击 **Save**。
4. 等待约 1–3 分钟，刷新此页面。页面顶部会出现网站地址，复制后即可发给学生。

以后如果要更新，只需在仓库里替换同名的 Excel 文件或网页文件，网站地址不会改变。

注意：网页首次打开需要联网，以便读取图表所需的公开 JavaScript 库。

本地预览需要通过静态网站服务打开文件夹（例如编辑器的 Live Server）。直接双击 `index.html` 可能因浏览器限制而无法读取 Excel。网站不需要后台数据库，也不会把课堂操作写回 Excel。
